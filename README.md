# 66日間 — 現実でレベルアップ

新しい行動が習慣になるまでの平均日数「66日」をチャレンジにした、スマホ向けの習慣トラッカー兼ワークアウト記録アプリです。
インストール不要のWebアプリ（PWA）で、iPhoneの「ホーム画面に追加」でアプリとして使えます。

## できること

| 画面 | 内容 |
| --- | --- |
| **今日** | 66日中の何日目か、連続日数・実績・XP。タスクごとの連続記録つきカード（アニメ風の一枚絵）。チェックで完了、回数タイプは＋−で記録。休む日は「スキップ」すれば連続記録が途切れない。過去の日にさかのぼって記録も可能。水分・起床時間・スクリーンタイムの記録。 |
| **トレーニング** | プッシュ／プル／レッグの自動ローテーション。前回の重量・回数を自動入力、セット完了で休憩タイマー（音とバイブ）、自己ベスト（推定1RM）の更新を検出。今週の総挙上量と先週比。 |
| **インサイト** | 最も高い能力から決まる「クラス」（ウォリアー、セージ、ローグ…）、累計完了数と目標ペースのグラフ、記録にもとづくタスク提案、ビフォーアフター、66日マップ、曜日別の達成率。 |
| **評価** | レベルとXP、5つの能力（知恵・自信・強さ・自制心・集中）の伸び、1日目／現在／66日目（予測）の切り替え、レーダーチャート、実績。 |

### XP と能力値

- タスク完了：20XP ＋ 連続日数×2XP（最大+30）。タスクに設定した能力が +2
- 完璧な日（全タスクを完了かスキップ）：+30XP、自制心・自信 +1
- ワークアウト：40XP ＋ セット数・総挙上量ボーナス。強さ +3、自制心 +1
- レベル L に必要な累計XP：40 × (L−1)²

## 使い方

初回はサンプルデータで中身を試せます。「自分の66日を始める」から、名前・自己評価・続けたいタスクを選ぶと1日目がスタートします。
データは端末のブラウザに保存されます（claude.ai で開いた場合はアカウントにも同期）。設定の「バックアップをコピー」で書き出し、「読み込む」で復元できます。

## 開発

ビルド不要の素のHTML/CSS/JavaScriptです。

```sh
python3 -m http.server 8000   # http://localhost:8000 を開く
```

```
index.html            エントリ
css/app.css           デザイン（トークンは :root）
js/data.js            能力・クラス・習慣プリセット・種目・実績
js/scenes.js          カード背景のアニメ風イラストをSVGで生成
js/store.js           状態・保存・XP/能力値の集計
js/app.js             画面とイベント
sw.js                 オフライン対応
scripts/build-single.mjs  全部を1枚のHTMLにまとめる
```

### 公開（GitHub Pages）

`main` に push すると `.github/workflows/pages.yml` が GitHub Pages に公開します。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
