# 00. プロダクト概要

## ゴール
GTO学習の3ステップ「調べる(Study) → 練習する(Practice) → 自分のプレイを直す(Analyze)」を、スマホ片手で気持ちよく回せるアプリにする。
市販のGTO学習ツールと同種の機能（解の閲覧、トレーナー、ハンド履歴分析、カスタム計算、レンジ作成）を揃え、**操作性・見た目・オフライン性**で上回る。

## ブランド（オリジナル）

| 項目 | 決定 |
|------|------|
| 名前 | **Tessera（テッセラ）** — ラテン語で「モザイクのタイル片」。13×13のレンジ表＝169枚のタイルのモザイク、というメタファー。 |
| タグライン | ポーカーGTOを、調べて・練習して・身につける |
| ロゴ | 2×2のタイル。対角の2枚が濃いゴールド、残りが半透明（`web/public/icons/icon.svg`） |
| 配色 | フェルト調の深緑ダーク＋ゴールドアクセント。ライトテーマあり（`06-ux-design.md`） |
| 書体 | システムフォント（オフライン・日本語対応・読み込みゼロ） |

> ⚠ 名前は仮決定。公開前に商標・ドメインの調査が必要（`web/src/lib/i18n` の `app.name` と `manifest.ts` の2か所で変更できる）。

## 他ツールより良くする点

| 領域 | 方針 | 現状(Phase 2) |
|------|------|---------------|
| 片手操作 | 主要ボタンは画面下半分、親指の届く範囲。練習中は下部ナビを隠して誤タップを減らす | ✅ |
| ジェスチャー | 右スワイプ=次のハンド、左スワイプ=解説、長押し=頻度表示 | ✅ |
| 触覚 | ボタン押下・正誤で振動（Vibration API。iOS Safariは非対応で無視） | ✅ |
| キーボード | F / C / R / A、数字キー、Enterで次へ、Eで解説 | ✅ |
| 1画面の解説 | **EV損失を最大の数字**で表示。頻度・EV・レンジ内の位置を1枚に収める | ✅ |
| 色覚多様性 | 標準(赤/緑/青)とOkabe–Ito系の切替＋模様（斜線/ドット）＋数値ラベル | ✅ |
| 速度 | スケルトン表示、操作は100ms以内に反応、解データは必要なチャンクだけ遅延読込 | ✅ |
| オフライン | PWA。解データを事前キャッシュし、機内モードでも練習できる | ✅ |
| 多言語 | 日本語（初期）/ 英語。用語集のツールチップ | ✅ |
| アクセシビリティ | WCAG AA（コントラスト検証済）、文字サイズ変更、スクリーンリーダー用ラベル | ✅（Phase 6で監査） |

## 対象外（当面）
- リアルマネー機能、対人プレイ、リアルタイム支援（RTA）。**学習専用**。
- 他社ソルバーの出力ファイルの再配布。取り込みは「ユーザー自身が権利を持つファイル」に限る。
