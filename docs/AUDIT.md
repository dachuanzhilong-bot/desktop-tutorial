## 7. スマホでの確認手順

1. `cd web && npm run build && node scripts/serve-static.mjs 3100`（または任意の静的ホスティングに `web/out/` を置く）。スマホから開く（同じWi-FiならPCのIPアドレス:3100。PWAとしてインストールするには HTTPS が必要）
2. **初回**: ホームで説明が3画面出る → 「練習をはじめる」で練習へ
3. **2タップ**: どの画面からでも 下の「練習」→「練習をはじめる」。ボタンが最初から見えていること
4. **練習**: 回答→結果→「解説」（左スワイプでも）→ 用語をタップすると説明が出る → 右スワイプで次へ。片手（親指）で全部届くこと
5. **模様**: スタディの表でレイズに斜線、コールに点（設定→「模様でも区別する」で切替）
6. **取り消し**: Range Builder でなぞって塗る→「取り消す」「やり直す」
7. **Analyze**: PokerStars のハンド履歴（.txt）を選ぶ → 進捗バーと「中止」、終わると一覧。画像など関係ないファイルを混ぜると「ハンドが見つからなかったファイル」に名前が出る
8. **オフライン**: 一度開いた後で機内モード → 上に「オフラインです」、練習・スタディはそのまま使える
9. **視差効果を減らす**: OSの設定（iOS: アクセシビリティ→動作→視差効果を減らす）をオン → 練習のカードがめくれずに表示される
10. **画面の読み上げ**: VoiceOver/TalkBack で練習の回答ボタン・結果（判定と EV 損失が読み上げられる）・13×13のマス（「AKs: レイズ 100%」など）
11. **同期（任意）**: `web/.env.local` に Supabase の URL と anon キー → ビルド → 設定でメールのコードでログイン → 2台で練習記録が揃う
