- スタディは画面の枠（見出し・タブ・深度）を静的HTMLに出し、最初の局面のデータを先に展開して描画を1回に、既定の解データを HTML から先読み（`preload`）。練習は設定画面を静的HTMLに、読み込み後に出るボタンでの画面のずれ（CLS 0.084）を解消。アニメーションのライブラリは練習・ICM 以外で読み込まない。
