### アクションの色（固定の意味）
| アクション | 標準 | 色覚配慮(Okabe–Ito系) | 模様(任意) |
|-----------|------|-----------------------|-----------|
| レイズ（小/大/オールイン） | `#c2373f` / `#9c2230` / `#6d1530` | `#b04800` / `#8a3800` / `#5c2500` | 斜線 |

すべて**白文字で4.5:1以上**（検証済: 5.3〜11.7）。本文/補助テキストも4.5:1以上（検証済: 6.1〜16.6）。判定色（最善/正解/…）は記号（★ ✓ △ ! ✕）と文字を併記し、色だけに頼らない。

### カード
4色デッキ（♠黒 ♥赤 ♦青 ♣緑。設定で2色に戻せる）。白地で各スートのコントラスト 5.4:1 以上。

## 操作仕様

| 操作 | 動作 |
|------|------|
| アクションボタン（高さ64px以上、画面下） | 選択。押下で振動(8ms)、結果で振動(良:14ms / 悪:28-40-28) |
| ボタン長押し(450ms) | ヒント（そのアクションのGTO頻度）。使うとスコア半減 |
| 結果カードを右スワイプ | 次のハンド |
| 結果カードを左スワイプ | 解説を開く/閉じる |
| 表のマス：タップ / 長押し(380ms) | 詳細 / 頻度ポップアップ |
| 表のマス：矢印キー | 選択移動（roving tabindex） |
| キーボード | `F` `C` `R` `A` / `1–9` / `Enter`,`Space`,`N`=次へ / `E`=解説 |
| 練習中 | 下部ナビを隠し、誤タップと画面の狭さを避ける |

## 速度
- 起動: HTMLとJSは静的配信。解のマニフェスト(約15KB gzip)→チャンク(数KB〜数十KB)を必要な順に読む。
- ロード中は骨組み(スケルトン)。クリック→画面反応は同期処理で完結（ネットワーク待ちなし）、100ms以内を目標。
- 1画面の描画: 13×13=169個のボタン。メモ化し、表示モード切替は再計算のみ。

## アクセシビリティ（WCAG 2.1 AA 目標）
- 色: 上記コントラスト検証、色覚配慮パレット+模様+数値ラベル。
- キーボード: すべて操作可能、フォーカスリング3px、スキップリンク。
- スクリーンリーダー: 表のマスに「AKs: レイズ 62%, コール 38%」の `aria-label`、結果は `aria-live`、ダイアログはネイティブ `<dialog>`（`showModal()`）でフォーカス管理・Esc対応。
- 動き: `prefers-reduced-motion` で全アニメーションを実質無効化。
- 文字サイズ: A− / A / A+ / A++（`html` のフォントサイズを変える。rem基準）。
- ツールチップ(用語集): ネイティブ `popover`（光消去・Escで閉じる）。
