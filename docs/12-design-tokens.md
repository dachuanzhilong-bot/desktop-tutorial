# 12. デザイントークンと画面の約束ごと

見た目の数値は **`web/src/app/globals.css` の1か所**で決めています。画面のコードでは数値を直書きせず、下のクラスを使います。

## 色

| トークン | 用途 |
|---------|------|
| `--bg` `--surface` `--surface-2` `--line` | 背景・カード・区切り線（ダーク／ライトで切り替え） |
| `--ink` `--muted` | 本文・補足の文字（どちらも背景に対して WCAG AA） |
| `--accent` `--accent-ink` `--accent-text` | 主ボタンとその文字、アクセント色の文字 |
| `--raise-1` `--raise-2` `--allin` `--call` `--fold` | アクションの色（意味は固定：レイズ＝赤系、コール＝緑、フォールド＝青）。色覚多様性向けの配色（`data-palette="cvd"`）あり |
| `--pat-raise` `--pat-call` | アクションの模様（レイズ＝斜線、コール＝点）。**既定でオン**（色だけで区別しないため。設定で消せる） |
| `--g-best` … `--g-blunder` | 5段階の判定の色（判定は必ず文字でも表示） |

Tailwind からは `bg-surface` `text-muted` `border-line` `bg-accent` などで使います（`@theme inline`）。

## 大きさ・角丸（`@theme`）

| クラス | 値 | 用途 |
|-------|----|------|
| `min-h-tap` `h-tap` `min-w-tap` | max(44px, 2.75rem) | **押せるものはすべてこれ以上**（文字を小さくしても44pxを下回らない） |
| `min-h-tap-lg` | max(48px, 3rem) | フォームの主ボタン |
| `min-h-cta` | max(56px, 3.5rem) | 画面の主役のボタン（「練習をはじめる」など） |
| `rounded-control` | 0.75rem | ボタン・入力欄・切り替え |
| `rounded-card` | 1rem | カード・パネル |
| `rounded-sheet` | 1.5rem | ダイアログ・結果のシート |
| `rounded-full` | – | チップ（丸い選択肢） |

文字の大きさは Tailwind の標準段階（`text-xs`〜`text-2xl`）だけを使い、全体の倍率は設定の「文字サイズ」（`--text-scale`）で変えます。

### 44px の例外（理由つき）

`e2e/ergonomics.spec.ts` が全画面で44px未満の操作要素を探します。例外は次だけです（WCAG 2.5.8 の最小24pxは満たす）。

- 13×13 表のマス（169マスをスマホ幅に収めるため約26px。ドラッグ・矢印キーでも操作可）
- Solve のカード選択（52枚を1画面に収めるため約27×40px）
- 文中の用語（タップで説明が出る単語）と文中のリンク

## 画面の約束ごと

- **片手操作**：主な操作は画面の下半分。練習の「はじめる」はタブバーの上に固定（どこからでも2タップで開始）
- **状態**：読み込み中はスケルトン、データなしは案内文、失敗は理由と「再試行」、オフラインは上部に通知、例外はエラー画面（真っ白にしない）
- **動き**：OS の「視差効果を減らす」に従う（CSS と framer-motion の `MotionConfig reducedMotion="user"`）
- **近似の表示**：解データを使う画面には `ApproxNote`（「近似」ラベル＋説明）
- **PC 幅（1024px〜）**：タブバーは左のサイドバーに、スタディは表と詳細を横並び、その他の画面は読みやすい幅（768px）
